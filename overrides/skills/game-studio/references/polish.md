# Focused polish workflow

Start with the requested player-visible result and the current evidence. Choose
only relevant roles: technical artist for drawing/rig/staging, engine specialist
for runtime/import/build, sound designer for dialogue/mix, QA reviewer for an
independent acceptance pass. Reuse available agents rather than spawning a studio.

Give each role distinct file ownership and a concrete artifact. Prioritize the
basics the user requested; fix identity, attachment, motion continuity, contact,
speech and depth before decorative effects. Carry out the authorized changes.

Render the changed moments promptly. Once defects are corrected, capture the
complete sequence and inspect transitions and extremes. A build log establishes
compilation, sampled images establish visible states, frame timing establishes
some temporal facts, and playback/audio audition establishes different evidence.
Keep those claims separate.

Finish with working artifacts and remaining limitations. Avoid adding project
templates or approval ceremonies that delay already authorized production work.
